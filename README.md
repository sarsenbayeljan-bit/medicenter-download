# MediCenter Desktop — жүктеу

Астанадағы клиникалар, дәрігерлер мен қабылдауларға арналған Windows қосымшасы (оқу жобасы).
ЖИ мен TOPSIS ең қолайлы дәрігер мен клиниканы ұсынады.

**Жүктеу беті:** https://sarsenbayeljan-bit.github.io/medicenter-download/
**Тікелей жүктеу:** [MediCenterDesktop_Setup.exe](https://github.com/sarsenbayeljan-bit/medicenter-download/releases/latest/download/MediCenterDesktop_Setup.exe)

## Орнату
1. `MediCenterDesktop_Setup.exe` жүктеп, іске қосыңыз (Windows ескертсе: «Толығырақ» → «Бәрібір іске қосу» — бағдарлама цифрлық қолтаңбасыз).
2. «Келесі» → «Орнату». Әкімші құқығы қажет емес.
3. Емделуші кіру терезесінде өзі тіркеледі; дәрігер мен мейірбике логинін клиника әкімшісі береді.

Талаптар: Windows 10/11 (64-bit). SQL Server міндетті емес — бағдарлама жергілікті базамен бірден жұмыс істейді.
